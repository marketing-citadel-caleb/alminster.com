# Images

Drop image files here with these exact names. No other edit is needed.

| File | Where it shows |
| --- | --- |
| `logo.png` (or .svg, .webp) | Replaces the text wordmark at the top of the home page and in the header |
| `portrait.jpg` (or .png, .webp) | The About section |
| `stream.jpg` (or .png, .webp) | Background of the "Play the stream here" panel |
| `social.png` (or .jpg) | Preview image when the site is shared on social media (1200 x 630) |
| `characters/<name>.jpg` | A character's card, e.g. `characters/brightwind.jpg` for "Brightwind" (name in lowercase) |

Keep each file under about 300 KB so the site stays fast.
